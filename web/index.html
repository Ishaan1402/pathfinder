Getting Started

How to run a training worker:

  1. Configure your search space and evaluation protocol in the Search Space tab.
  2. Set HPO_BROKER_URL and HPO_STUDY_NAME on your training machine. See docs/INTEGRATION.md for details.
  3. Run the worker script on your GPU machine. The worker will connect to this broker, request trials, and report epoch metrics.
